# Performance-Based Concrete Inverse Design — Industry Evaluation Edition

## Purpose
This package wraps the frozen V3.3 inverse-design engine in an engineering-focused evaluation interface.

## Run locally
Open Command Prompt in this folder and run:

    python -m streamlit run app_industry.py

## Interface
1. Design
2. Results
3. Analysis
4. Qualification

## Analysis panels
- Independent performance verification
- Multi-candidate composition comparison
- Constraint analysis
- Applicability / local data support
- Similar historical mixtures
- Design-space map
- Discrete w/cm constraint scenario analysis
- Engineering qualification requirements

## Important
This is a research prototype. Generated mixtures are candidates for technical evaluation and
trial batching, not approved concrete mixture designs. Physical testing and project-specific
engineering qualification remain necessary.

The V3.3 computational engine is frozen in this package. The industry interface changes
presentation and analysis, not the underlying model.
